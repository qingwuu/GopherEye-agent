# Treatment Resource Index

This index lists treatment and management resource slots. It intentionally does
not provide treatment recommendations until reviewed sources are added.

## Needed Resource Slots

```text

grape anthracnose management
nutrient deficiency management
insect or mite damage management
healthy/normal variation reassurance
fungicide resistance management
region-specific pesticide label references
```

## Add A Resource

Place raw materials in:

```text
raw/sources/treatment_resources/
```

Then create a reviewed wiki page only after human review.

Recommended page path:

```text
wiki/treatment_resources/<disease_or_condition>_management.md
```

Each reviewed page should follow
[Treatment Resource Policy](treatment_resource_policy.md).
