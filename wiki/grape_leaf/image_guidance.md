# Grape Leaf Image Guidance

This page defines what image information is useful for GopherEye diagnosis.

## Minimum Useful Image

A useful grape leaf image should show:

```text
the same leaf clearly
the relevant surface: adaxial or abaxial
the symptomatic region in focus
enough surrounding lamina to judge pattern
primary veins if lesion geometry matters
natural or even lighting
```

## Recommended Image Set

For diagnostic workflows, the app should encourage:

```text
1. adaxial surface of the symptomatic leaf
2. abaxial surface of the same leaf
3. close-up of the symptomatic area
4. wider context image showing leaf position if needed
```

## Poor Image Conditions

Request a better image when:

```text
blur prevents symptom inspection
lighting hides surface texture
overexposure removes color details
leaf is occluded
only petiole or background is visible
the side is impossible to identify
```

## User-Facing Request Template

```text
Please upload a clear image of the underside of the same leaf. Keep the leaf in
focus, include the area with visible spots, and use even lighting if possible.
```
