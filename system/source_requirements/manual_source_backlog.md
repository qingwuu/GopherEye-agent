# Manual Source Backlog

This page tracks information that should be manually searched, collected, or
requested from experts before the curated wiki makes stronger claims.

## Highest Priority

```text
1. Expert information about grape leaf disease visual diagnosis.
2. Reviewed front/back examples with the same leaf photographed from both sides.
3. Treatment or management resources from authoritative extension/IPM sources.
4. Expert diagnosis scripts: the questions and checks an expert uses.
5. Dialog tree examples for multi-turn user interaction.
6. Disease-specific source notes for powdery mildew, downy mildew, black rot,
   nutrient deficiency, insect damage, and healthy/normal variation.
```

## Where To Put Materials

Simple wiki-ready notes can go directly under `wiki/`. Use these raw folders
only when preserving source files or review artifacts is useful:

```text
raw/sources/expert_information/
raw/sources/expert_examples/
raw/sources/treatment_resources/
raw/sources/diagnosis_scripts/
raw/sources/procedure_notes/
raw/sources/dialog_trees/
raw/sources/disease_information/
```

Each folder has a README with optional collection notes.

## Collection Targets

Expert information should answer:

```text
What visual evidence matters most?
Which symptoms require the underside?
Which symptoms are frequently confused?
What confidence boundary separates possible, provisional, and confirmed?
Which normal structures should not be called symptoms?
```

Expert examples should include:

```text
front image
back image
same-leaf pairing evidence
expert label
expert rationale
evidence present
evidence missing
diagnosis status
allowed follow-up questions
```

Treatment resources should include:

```text
resource title
authoritative organization
publication date or access date
region or crop context
disease coverage
non-chemical management content
chemical management content, if any
label/regulatory caveats
reviewer notes
```

Diagnosis scripts should include:

```text
first question to ask
image quality checks
front/back request wording
differential diagnosis checks
treatment question guardrails
handoff-to-expert conditions
```
