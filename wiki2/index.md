# GopherEye Wiki2

Wiki2 is a split-page copy of `wiki/` for token-cost experiments. It keeps the same knowledge boundary, but breaks large pages into small detailed section pages so retrieval can select less context.

## Retrieval Pattern

```text
1. Search parent pages for routing.
2. Search detailed section pages by heading and search_cues.
3. Load only the smallest sufficient detailed pages.
4. Do not load all sibling pages unless the question asks for comparison.
```
